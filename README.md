Система автоматического улучшения качества фотографий (яркость, контраст, резкость)

Описание

Проект предназначен для автоматического улучшения качества фотографий с использованием методов компьютерного зрения и глубокого обучения.

Используемые технологии

* Python
* OpenCV
* NumPy
* Matplotlib
* Google Colab
* Caffe DNN

Основные функции

* Коррекция яркости и контрастности.
* Повышение резкости изображений.
* Уменьшение шума.
* Автоматическое раскрашивание чёрно-белых фотографий.
* Сравнение характеристик изображений до и после обработки.

Результат

Система позволяет улучшать визуальное качество фотографий и оценивать эффективность обработки по измеряемым характеристикам.
